# MechNow — find a verified mechanic near you in minutes

Your vehicle breaks down. MechNow shows the verified local mechanics actually near you — small garages, tyre shops, battery specialists, mobile mechanics and EV specialists — with upfront fixed charges and live ETA. Book in two taps and track the job.

## What is inside

- Emergency finder: 7 problem types, Bike/Car toggle, 6 cities, filters for open now, mobile mechanic, EV specialist and top rated.
- 49 verified seed mechanics with fixed per-problem pricing, ratings and real open-hours logic.
- Booking with a live status timeline, Join as a mechanic onboarding, trust and safety band, FAQ.
- Full portfolio-grade treatment: dark mode, glass UI, scroll animations, legal pages (privacy, terms, DMCA).

All state persists in the browser via localStorage (key mechnow_v1). Prices, commission and listings are illustrative demo data.

## Tech

Zero-build static site: a single self-contained index.html (inline CSS + JS, no external requests) plus legal.html, vercel.json security headers, robots.txt and sitemap.xml.
